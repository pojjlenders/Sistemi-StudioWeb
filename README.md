# AppLayer 2000 – Il web e i protocolli applicativi

Sito divulgativo e interattivo (Laboratorio di Sistemi e Reti) su **HTTP, DNS, HTTPS/TLS e SMTP**, con approfondimenti su TCP/UDP, cache, cookie, CORS e autenticazione email (SPF, DKIM, DMARC).

- **Teoria**: 20 sezioni
- **Laboratorio**: 11 simulatori interattivi
- **Studio**: quiz (50 quesiti), flashcard, giochi, glossario
- **Detective**: 10 casi di diagnosi su log reali

Sito statico (HTML, CSS, JavaScript vanilla): nessun backend e nessuna dipendenza esterna. Si apre anche direttamente da file (`index.html`).
